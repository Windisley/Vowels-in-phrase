# Contador de Vogais em uma Frase

Este projeto é um simples **contador de vogais** que verifica quantas vogais existem em uma frase fornecida pelo usuário. O código conta as vogais **independente de maiúsculas ou minúsculas** e exibe a quantidade de vogais encontradas, além de listar quais são elas.

![code](https://github.com/user-attachments/assets/7044370e-b4a1-4e72-8f9b-067fd48e0c59)


## Funcionalidade

- O código solicita ao usuário que insira uma frase.
- A função `converseVowel` percorre a frase e conta quantas vogais (a, e, i, o, u) aparecem na frase.
- O programa exibe a quantidade de vogais e lista todas as vogais encontradas.

## Como Usar

1. Clone o repositório para a sua máquina local:

git clone https://github.com/seu-usuario/seu-repositorio.git

2. Acesse o diretório do projeto:

    cd seu-repositorio

3. Execute o script em Python:

    python contador_vogais.py

4. O programa solicitará que você insira uma frase. Após a inserção, ele retornará a quantidade de vogais e as vogais presentes na frase.
